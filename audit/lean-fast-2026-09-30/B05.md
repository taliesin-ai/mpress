# B05 — dialog focus qualification, 2026-10-01

Beads `mp-b52.2.5`. Investigation resolved with a corrected test and an evidence-based no-change decision for production.

## Diagnosis

The private image test invoked JavaScript `.click()` without focusing the image trigger, then expected Escape to restore focus to that trigger immediately. A script click does not establish keyboard focus. The native dialog returns to the previously focused control, so that expectation did not model keyboard activation.

The public replay establishes focus on the existing visible theme control and compares 48 real activation cases with 12 script-click controls. Enter, Space, native mouse and native touch correctly restore the activated opener. Script clicks correctly restore the prior theme control. The stale oracle reproduces exactly twelve failures while all 48 native controls pass; a separate initial setup failure was corrected by waiting until the opener can receive input. No production handler or modal behavior was changed.
