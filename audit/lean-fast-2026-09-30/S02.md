# Generated route safety — Beads mp-b52.1.2

Baseline: `0623f38`, after the separately qualified build/clean output guard. Slugs could escape the selected output directory; duplicate routes were compared before filesystem normalization. Pages could also collide with generated files, static files or another language's output after the previous site had been deleted.

The shared `internal/routes` contract validates components before path cleaning. It rejects dot segments, backslashes, drive/stream syntax, Windows device names, invalid UTF-8, control characters, query/fragment characters and ambiguous nested URL escapes. Single safe URL escapes become logical unescaped route components; repeated slashes normalize consistently. Root routes, nested routes, numeric filename prefixes and Unicode remain supported. Language configuration must contain single valid path components.

Build treats unsafe and duplicate routes as fatal in both modes. Preflight registers actual output files and their parent directories across every language, generated artifacts, static files and mounted snapshots before output removal. Case and Unicode-normalization aliases are compared deterministically. Existing static overrides remain supported; ordinary `knowledge/index.html` coexists with `knowledge/index.json`. Optional namespaces are reserved when their producers are enabled. Both knowledge data formats are protected because artifact cleanup can remove stale JSON or gzip files; an unused `manifest.json.gz` path is not reserved.

The parse-cache version advances to v22, and preflight checks cached URL/output consistency independently. The page writer also rejects noncanonical or escaping filenames before rendering or directory creation. No product feature or third-party dependency was added.

## Remaining boundaries

This closes generated-page routing, not the whole filesystem audit or the feature-freeze goal. Authoring confinement remains `mp-b52.1.3`, static symlink publication remains `mp-b52.1.4`, general failed-build staging remains `mp-b52.1.5`, and version artifact trust remains `mp-b52.1.7`. Build can still write its project-local parse cache during parsing. This qualification does not claim protection against concurrent hostile filesystem rearrangement, every host's URL rewriting, or complete native device/platform coverage. Broad locale/navigation qualification and the four known private failures remain open.
